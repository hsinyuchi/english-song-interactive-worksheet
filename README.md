在您的 AI Coding Agent（例如 **Google Antigravity**、**Cursor**、**Claude Code** 等）對話框中直接輸入以下指令：

## ✨ 核心特色與教學亮點 (Key Features)

1. **📱 手機友善行內三選一 (Mobile-First Inline Popover)**：
   - 點擊歌詞空格即在下方彈出三選一浮動按鈕，單手即可作答，免除上下滑動尋找字庫的痛點。
2. **🎯 高品質辨音干擾項 (Phonological Distractors)**：
   - 每個挖空均設計 2 個近音、押韻或拼字易混淆干擾詞（如 `submission` vs `commission / permission`），落實聽力辨音教學。
3. **🔊 原生語音朗讀 (Web Speech API TTS)**：
   - 單字庫與實用例句旁內建發音按鈕，免付費 API，點擊即可聆聽標準美式發音。
4. **🎚️ 1 ~ 5 星推薦指數互動滑桿 (Rating Slider)**：
   - 連動五星視覺圖示與推薦標籤，提供學生趣味的情意表達管道。
5. **🎉 4 級遊戲化動態特效 (Gamified Visual Feedback)**：
   - 根據得分觸發：**80+ 分彩帶灑花 (Confetti)**、**60+ 分熱氣球升空**、**及格邊緣畫面震動**、**待加強灰階下雨**。
6. **📝 108 課綱學習歷程數位成果認證卡 (Proof of Learning)**：
   - 包含完整作答耗時、聽力得分、A1~A2 雙語教師激勵短評。
   - **完整收錄學生反思問答（推薦原因 + 歌詞啟發，絕不截斷！）**，一鍵匯出高解析度 PNG 圖檔供學習歷程檔案上傳。
7. **☁️ 一鍵部署至 Cloudflare Pages**：
   - 自動打包為單檔 `site.zip`，30 秒無腦拖曳上傳即可獲得專屬 HTTPS 網址，支援手機順暢播放 YouTube！

## 🛠️ 使用方式範例 (Usage Example)

安裝後，在 Agent 對話中直接說：

> *「請幫我把 Bruno Mars 的《Count on Me》做成英語歌曲互動學習單！」*  
> *「請幫我把 Taylor Swift 的《Cruel Summer》做成這款 10 題三選一學習單！」*

AI 將自動遵循 SOP 完成歌詞檢索、10 題挖空辨音設計、單字發音庫、文法解析、反思問卷，並產出完整的單檔 `index.html` 與部署壓縮包。
